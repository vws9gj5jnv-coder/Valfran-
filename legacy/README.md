avant la refonte complète. Elle n'est plus construite ni déployée.

Restaurer cette version : `git checkout 2ee9ad6 -- .` (ou consulter l'historique Git).

- avis clients de démonstration (non authentiques) ;
- section « véhicules d'occasion » (hors périmètre de la nouvelle mission) ;
- coordonnées fictives (SIRET, téléphone) présentées comme réelles.
